# Squirrel Sightseeing Tracker

A simple Python project to record and store squirrel observations (species, color, and GPS coordinates) into Firebase Realtime Database. Designed for environmental tracking and wildlife logging.

##Project Overview

This script allows users to:
- Add new squirrel sightings (species, color, latitude, longitude)
- Automatically upload them to Firebase Realtime Database
